# Movilidad Sustentable Universitaria (Ecomovi PWA)

PWA para la gestión de movilidad sustentable en el campus universitario[cite: 75, 82]. Este proyecto busca implementar un sistema que disminuya la congestión vehicular y la huella de carbono mediante un sistema de carpooling y control de accesos con QR[cite: 87, 88].

## Sobre el Proyecto

Este sistema nace como una solución para optimizar el uso de los estacionamientos, reducir el número de vehículos de ocupación individual y establecer un protocolo de acceso eficiente y seguro para la comunidad universitaria[cite: 87, 88].

### Funcionalidades Principales

* **Registro de Usuarios:** Creación de cuentas para la comunidad universitaria[cite: 103].
* **Carpooling:** Módulo para publicar, buscar y gestionar viajes compartidos[cite: 105].
* **Control de Acceso:** Generación y validación de códigos QR para el acceso vehicular[cite: 104].
* **Asignación de Espacios:** Asignación automatizada de lugares de estacionamiento[cite: 104].
* **Dashboard de Métricas:** Panel para visualizar indicadores clave como la reducción de CO2 y la ocupación del estacionamiento[cite: 106].

### Construido Con

Este proyecto está siendo desarrollado con las siguientes tecnologías:

* **[Angular](https://angular.io/):** Framework de desarrollo frontend[cite: 116].
* **[PrimeNG](https://primeng.org/):** Biblioteca de componentes UI para Angular[cite: 118].
* **[Supabase](https://supabase.com/):** Plataforma Backend-as-a-Service de código abierto[cite: 114].
* **Progressive Web App (PWA):** Para una experiencia de usuario accesible desde cualquier dispositivo sin necesidad de instalación[cite: 110].

## Empezando

Sigue estos pasos para obtener una copia local del proyecto y ponerla en funcionamiento.

### Prerrequisitos

Asegúrate de tener Node.js (versión 22.x) y Angular CLI instalados.

* npm
    ```sh
    npm install -g @angular/cli
    ```

### Instalación

1.  Clona el repositorio
    ```sh
    git clone [https://github.com/TU_USUARIO/ecomovi-pwa.git](https://github.com/TU_USUARIO/ecomovi-pwa.git)
    ```
2.  Navega a la carpeta del proyecto
    ```sh
    cd ecomovi-pwa
    ```
3.  Instala los paquetes de NPM
    ```sh
    npm install
    ```
4.  Crea tu archivo `environment.ts` en `src/environments/` con tus claves de Supabase.
